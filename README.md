# z_Writer Studio v6

z_Writer Studio は、AIチャット作品の「作品紹介」と「キャラクター紹介」を、公開用に見栄えよく整えるための静的Webアプリです。

## v6 の主な変更

- ボタン処理をイベント委譲方式へ全面整理
- 装飾パレット・Markdownボタン・コピー・ブロック挿入を同じ仕組みで処理
- スワイプ画面移動なし。上部タブのみ
- 作品紹介用「ブロック挿入パレット」を追加
- キャラクターごとの「ブロック挿入パレット」を追加
- 基本情報 / セリフ / 第一印象 / 性格 / ギャップ / 恋愛重視 / ミステリアス / 対立 / {{user}}との関係 / 締め
- 作品紹介と各キャラクター紹介を個別コピー
- 冒頭約420文字だけを見る「ファーストビュー確認」
- localStorage 自動保存
- GitHub Pagesへそのまま公開可能

## GitHub Pages

1. 新しいGitHubリポジトリを作成
2. `index.html` `styles.css` `app.js` をリポジトリ直下へ置く
3. Settings → Pages
4. Source を `Deploy from a branch`
5. `main` / `/(root)` を選択して保存

ビルド不要です。
