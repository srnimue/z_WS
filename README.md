# z_Writer Studio

z_Writer Studio は、AIチャット作品向けの「全体紹介文」と「キャラクター紹介文」をスマホ中心で編集するための、非公式・静的Webアプリです。

## 主な機能

- Story / Characters / Preview / Check の4画面
- スマホで左右スワイプ、上部タブでも移動
- 全体紹介文＋キャラクター紹介文の合計文字数カウント
- 10,000文字上限のメーター表示
- キャラクター紹介カードの追加・複製・削除
- 基本Markdown補助（見出し、太字、引用、箇条書き）
- スマホ幅プレビュー
- センシティブ語の注意表示
- 未確認Markdown記法の検出
- 長すぎる段落の警告
- localStorageによる自動保存
- 全文コピー / TXT書き出し

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成
2. このフォルダ内の `index.html` `styles.css` `app.js` をリポジトリ直下へアップロード
3. GitHubのリポジトリで **Settings → Pages**
4. **Build and deployment → Source** を `Deploy from a branch` にする
5. Branch を `main`、Folder を `/(root)` に設定して Save
6. 数分後、PagesのURLからアクセスできます

ビルド作業は不要です。

## ローカルで試す

`index.html` を直接開いても動作します。

ブラウザによってはクリップボード機能が `file://` では制限されるため、コピー機能まで確認する場合は簡易HTTPサーバーを使ってください。

例:

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## データ保存について

入力内容はブラウザの `localStorage` に保存されます。サーバー送信は行いません。
ブラウザデータを消去すると保存内容も消えるため、重要な文章はTXT書き出しも利用してください。

## Markdownについて

このアプリのプレビューは、意図的に基本記法だけを簡易サポートしています。

- `##` / `###` 見出し
- `**太字**`
- `> 引用`
- `- 箇条書き`
- `---` 罫線

取り消し線、Markdownリンク、画像、コードブロック、HTML、表などは「要確認」としてCheck画面で通知します。
